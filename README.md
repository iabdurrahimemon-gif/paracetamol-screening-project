# Rapid Screening of Potentially Substandard Pharmaceuticals Using UV-Vis Spectroscopy and Machine Learning

## Abstract
Substandard, degraded, or falsified medications present severe global health hazards. While high-performance liquid chromatography (HPLC) and mass spectrometry offer high precision for drug quality verification, they are resource-intensive, expensive, and impractical for preliminary field triage. This project establishes a rapid, low-cost computational screening model leveraging ultraviolet-visible (UV-Vis) spectral fingerprinting combined with machine learning classification algorithms to evaluate paracetamol sample integrity.

---

## 1. Objective
To develop and deploy a rapid screening framework capable of analyzing key UV-Vis spectral descriptors—such as maximum absorption wavelength ($\lambda_{max}$), peak height, full width at half maximum (FWHM), and area under the curve—to instantly categorize pharmaceutical samples into distinct quality classes:
* **Genuine**
* **Substandard / Low-Dose**
* **Wrong API (Substitute)**
* **Degraded / Impure**

---

## 2. System Architecture & Methodology
The analytical pipeline follows a structured workflow:
1. **Spectral Data Processing:** Ingestion and preprocessing of raw optical absorbance data, applying baseline corrections and noise smoothing.
2. **Feature Extraction:** Automated computation of characteristic peak properties within the paracetamol absorption band ($\sim 230 - 260\text{ nm}$).
3. **Machine Learning Classification:** Utilizing optimized ensemble classifiers (Random Forest) trained on synthetic and empirical spectral profiles to predict sample categories with quantified uncertainty metrics.
4. **Interactive Deployment:** A Streamlit-based web application providing batch CSV screening, individual parameter tuning, and high-resolution spectral visualizers.

---

## 3. Technology Stack
The application is built using a robust, modular Python ecosystem:
* **Python**: Core programming language for data preprocessing and backend logic.
* **Pandas & NumPy**: Vectorized data manipulation, matrix computations, and statistical transformations.
* **Scikit-learn**: Training, evaluation, and serialization of the multi-class classification models.
* **Matplotlib**: Generation of high-definition, publication-ready spectral plots, confusion matrices, and ROC curves.
* **Streamlit**: Interactive frontend web application framework.
* **Joblib**: Efficient model persistence and deployment artifact management.
